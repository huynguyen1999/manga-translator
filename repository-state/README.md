# Repository state

This directory is the project's durable memory for future contributors and coding agents.

- `CURRENT.md`: short current-state overview and links to relevant contracts.
- `CURRENT_DETAILS.md`: deferred detailed snapshot for subsystem-specific history and architecture.
- `LAYOUT_AND_TEXT_MERGE_RULES.md`: compatibility contract for OCR grouping, free-text coalescing, ownership, placement, and final validation.
- `BUGS.md`: lessons from discovered bugs, including how to avoid repeating them.
- `CHANGES.md`: concise history of new features and large changes.

Update `BUGS.md` whenever a bug is discovered. Update both `CURRENT.md` and `CHANGES.md` whenever a feature or large change alters the repository's behavior, architecture, dependencies, storage, API, or development workflow.

Do not copy commit logs or list every edited file here. Record only information that will help the next person understand or safely change the repository.
